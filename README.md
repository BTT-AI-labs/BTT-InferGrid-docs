# BTT InferGrid Docs

This repository contains the bilingual documentation site for BTT InferGrid.

## Development

```bash
yarn install
yarn start
```

Start the Chinese locale:

```bash
yarn start-zh
```

Build the site:

```bash
yarn build
```

## Structure

- `docs/`: English documentation.
- `i18n/zh-Hans/docusaurus-plugin-content-docs/current/`: Chinese documentation.
- `sidebars.js`: English sidebar configuration.
- `i18n/zh-Hans/docusaurus-plugin-content-docs/current/sidebars.js`: Chinese sidebar configuration.
