# BTT InferGrid

**BTT InferGrid** is a distributed infrastructure layer for AI inference workloads, helping developers integrate model capabilities into stable, observable, and scalable production systems.

:::info Documentation Version
The English documentation is the primary version. The Chinese documentation follows the same structure to facilitate bilingual team collaboration.
:::

## What InferGrid Provides

- Distributed inference access capabilities for AI applications and agents
- API-first integration suitable for backend services, scripts, and product workflows
- Operation guides around model routing, usage monitoring, and production deployment
- Bilingual documentation in English and Chinese for global developer collaboration
