# BTT InferGrid

BTT InferGrid is an inference infrastructure layer for running AI workloads across distributed compute resources. It is designed for teams that need a reliable path from model access to production-grade inference, with clear controls for deployment, usage, and integration.

The documentation is organized for builders who want to evaluate the platform quickly, connect applications through APIs, and understand how InferGrid fits into a broader compute and AI service stack.

## What InferGrid Provides

- Distributed inference access for AI applications and agents
- API-first integration for backend services, scripts, and product workflows
- Operational guidance for model routing, usage monitoring, and production rollout
- Bilingual documentation for English and Chinese developer teams

## Documentation Structure

Start with the quick start if you want to make a first request. Read the architecture guide if you are evaluating how InferGrid should fit into your system. Use the API reference as the contract surface when wiring production integrations.
