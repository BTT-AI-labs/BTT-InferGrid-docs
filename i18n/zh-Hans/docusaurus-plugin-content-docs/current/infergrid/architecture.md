# 架构说明

BTT InferGrid 位于应用和分布式推理算力之间。应用向 InferGrid 发送经过鉴权的推理请求，InferGrid 负责请求校验、路由、执行调度和标准化响应返回。

## 核心流程

1. 应用向 InferGrid API 发送带鉴权信息的请求。
2. InferGrid 校验请求并选择合适的推理路由。
3. 被选中的计算资源执行推理工作负载。
4. InferGrid 将标准化结果返回给应用。
5. 系统记录用量数据，用于可观测性、计费和运营分析。

## 集成方式

生产环境建议把 InferGrid 的访问放在可信后端服务中。客户端应用访问你的后端，由后端使用服务端凭证调用 InferGrid。

```text
用户应用 -> 你的后端 -> BTT InferGrid -> 分布式算力
```

## 运营注意事项

- 鉴权：API key 应存放在密钥管理系统或服务端环境变量中。
- 可靠性：对临时错误配置带退避策略的重试。
- 可观测性：记录 request ID、模型名、延迟和错误码。
- 权限治理：区分开发环境和生产环境 API key。
- 成本控制：设置用量预算，并定期查看消耗。
