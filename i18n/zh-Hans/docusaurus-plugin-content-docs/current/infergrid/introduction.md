# BTT InferGrid

BTT InferGrid 是面向 AI 推理工作负载的分布式基础设施层，帮助开发者把模型能力接入到稳定、可观测、可扩展的生产系统中。

这套文档面向需要快速评估、接入 API、理解系统架构的开发者和团队。默认英文文档作为主版本，中文文档与英文结构保持一致，方便双语团队协作维护。

## InferGrid 提供什么

- 面向 AI 应用和 Agent 的分布式推理接入能力
- API 优先的集成方式，适合后端服务、脚本和产品工作流
- 围绕模型路由、用量监控、生产部署的操作指南
- 中英文双语文档，方便国内外开发者共同使用

## 文档结构

如果你想尽快完成第一次调用，请从快速开始读起。如果你正在评估系统设计，请阅读架构说明。正式接入时，可以把 API 参考作为接口契约来使用。
